PyLingo Privacy Policy

Effective Date: September 24, 2026

PyLingo is a mobile application designed to help users learn Python through lessons, quizzes, guided projects, progress tracking, streaks, achievements, and practice activities. This Privacy Policy explains how information is handled when you use the PyLingo application.

1. No Account Required

PyLingo does not currently require users to create an account, sign in, or provide personal information such as a name, email address, phone number, or password.

Users can access the learning experience without registration.

2. Learning Progress

PyLingo stores learning-related information locally on your device, including:

  • completed lessons and modules
  • course progress
  • hearts/lives
  • streak information
  • achievements
  • selected course
  • onboarding and application settings

This information is stored on the device and is used to provide the learning experience. PyLingo currently does not provide cloud synchronization or account-based backup of this progress.

If the application is deleted, its local data is cleared, or the device is replaced, locally stored progress may be lost.

3. Internet and Remote Course Content

PyLingo connects to the internet to download course content and application curriculum. Course content is delivered using cloud infrastructure, including services provided by Amazon Web Services (AWS), such as Amazon S3 and Amazon CloudFront.

When the application connects to these services, standard technical information may be processed automatically by the network or hosting provider, such as:

  • IP address
  • request date and time
  • device or network information
  • requested content or file
  • technical information required to deliver the content

This information may be processed by the infrastructure provider for content delivery, reliability, security, and abuse prevention. PyLingo does not use this technical information to create advertising profiles.

4. Advertising

PyLingo does not currently display third-party advertisements. PyLingo does not sell personal information to advertisers and does not use user information for targeted advertising.

5. Analytics and Tracking

PyLingo does not currently use third-party advertising trackers.

If analytics, crash reporting, cloud accounts, or similar services are added in a future version, this Privacy Policy will be updated to explain what information is collected and how it is used.

6. Device Features

PyLingo may use basic device functionality to improve the learning experience, including:

  • sound effects
  • haptic or vibration feedback
  • local device storage
  • internet access for downloading course content

These features are used only to provide application functionality.

7. Children

PyLingo is an educational application for learning programming. The application does not knowingly request or collect personal information from children.

Users should use the application in accordance with the age requirements and policies of the applicable app store and device platform.

8. Third-Party Services

PyLingo may rely on third-party infrastructure providers necessary to operate the application, including Amazon Web Services (AWS), which is used for hosting and delivering curriculum and application content.

The operating system and app distribution platform, such as Google Play or the Apple App Store, may also independently collect information according to their own privacy policies.

9. Data Sharing

PyLingo does not sell or rent users' personal information. We do not intentionally share personally identifying information with third parties for marketing or advertising purposes.

Technical information may be processed by service providers where necessary to operate and deliver the application.

10. Data Security

We take reasonable steps to design PyLingo so that unnecessary personal information is not collected. Learning progress is stored locally on the user's device, while remote curriculum content is delivered through established cloud infrastructure.

No method of electronic storage or internet transmission can be guaranteed to be completely secure.

11. Data Retention and Deletion

Because PyLingo currently stores learning progress locally, users can remove this information by:

  • using the application's Reset Progress feature, where available; or
  • uninstalling the application from the device.

PyLingo does not currently maintain a user account database containing learning progress.

12. Changes to This Privacy Policy

This Privacy Policy may be updated if PyLingo introduces new functionality, services, analytics, account systems, cloud synchronization, or other features that affect how information is handled.

The updated policy will include a revised effective date.
